= openCenter GitOps Base -- Release 2026.01

*Release Date:* April 2026 +
*Scope:* Q1 2026 (January -- March)

'''

== Highlights

This release delivers a major architectural refactor enabling flexible community and enterprise deployment patterns, along with significant documentation improvements and critical bug fixes across the platform services stack.

'''

== Breaking Changes

* *Namespace rebrand:* All source references migrated from `rackerlabs` to `opencenter-cloud`
* *Managed services removed from base:* `managed-services` directory removed; cluster repos must source these independently

'''

== Major Refactors

=== Community / Enterprise Layout Split

14 services refactored to support dual sourcing patterns, enabling clusters to choose between public upstream sources (community) or private mirrored sources (enterprise):

* cert-manager
* gateway-api
* headlamp
* istio
* keycloak
* kube-prometheus-stack
* kyverno
* loki
* metallb
* olm
* opentelemetry-kube-stack
* postgres-operator
* rbac-manager
* strimzi-kafka-operator
* vsphere-csi

=== Kustomize Component Migration

* Keycloak and strimzi-kafka-operator migrated to the Kustomize component pattern (ADR-001 implementation complete)
* Common resources consolidated into `global/`

'''

== New Features

* *vsphere-csi:* Added `CSINodeTopology` CRD for topology-aware provisioning
* *vsphere-csi:* Added `CnsVolumeOperationRequest` CRD
* *strimzi-kafka-operator:* Upgraded to v0.50.0
* *gateway-api:* Updated base `values.yaml` reference
* *envoy:* Enabled Backend CRD support

'''

== Bug Fixes

* *istio:* Fixed drift detector for `istio-validator-istio-system`, set default replica counts, refactored configuration, disabled gateway-api in istiod
* *keycloak:* Updated version, created operator ServiceAccount, switched to internal CatalogSource
* *postgres-operator:* Fixed ServiceAccount handling
* *rbac-manager:* Disabled ServiceMonitor to prevent scrape conflicts
* *alert-proxy:* Corrected namespace reference
* *vsphere-csi:* Removed duplicate `CSIStorageCapacity` CRD (provided by Kubernetes core)

'''

== Documentation

* Added reference documentation for all services (Phase 4 B3.1)
* Added architecture explanation docs (Phase 4 B3.2)
* Added service deployment examples and configuration update guides
* Completed security remediation roadmap (6 findings marked as false positives)
* Refactored and refined overall documentation structure

'''

== Upgrade Notes

. *Source URLs:* If you reference `rackerlabs` in cluster overlays, update to `opencenter-cloud`.
. *Managed services:* Clusters using `managed-services` from base must now source them from the enterprise repo or define them locally.
. *Kustomize components:* Services migrated to the component pattern may require overlay adjustments--see individual service READMEs.

'''
