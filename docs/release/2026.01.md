## Scope limitation

The previous version of this page attributed source renames, managed-service removal, Kustomize migrations, service upgrades, and security outcomes to this release. Those claims are not established by the first-parent tag-commit diff and are removed here rather than presented as facts.

## Consumer guidance

**Consumer responsibility:** Before adopting the tag, inspect the consuming repository's Flux `GitRepository` refs, Kustomization paths, override values, secrets, and any private overlays. Confirm the selected service manifests and chart versions from the tag itself. No repository evidence here establishes a safe upgrade sequence for every consumer.

**Private repository responsibility:** If a private enterprise repository imports this base, its owner must verify the base ref, patches, private sources/images, credentials, and compatibility. None of that repository is present here.

**Runtime responsibility:** Reconcile and health-check the selected resources in the target cluster. A Git tag alone does not prove successful Flux, Helm, OLM, or workload reconciliation.

## Do not attribute later changes to this release

Changes after the tag, including KEDA service content and the inventory catalog implementation, are outside the first-parent comparison and are not asserted as part of the `2026.01` tag.
